Rest · tap to expand
Why this layout
Row height is 56px — every interactive control meets the 44×44 touch target rule, including the swipe gesture surface. Weight + reps use Geist Mono so 7-digit set logs (e.g. 102.5 × 12) never shift the column.
Interactions
Tap weight/reps → opens numeric bottom-sheet pad. RPE chip → opens 6–10 picker. Swipe row right→left completes (haptic medium). Long-press → context menu (Edit, Duplicate, Note, Remove).
Rest timer
Auto-starts on set complete. 60s isolation / 90s compound default. Background-safe (system notification at 10s + 0s). Tap to expand into full sheet (see next screen).
